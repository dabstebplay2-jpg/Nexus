Nexus Pro — как запускать (Windows)
====================================

БЫСТРЫЙ СТАРТ
  1. Один раз: install-deps.bat
  2. Каждый раз: start-all.bat
  3. Браузер: http://localhost:5173

ОТДЕЛЬНЫЕ СЕРВИСЫ
  start-cloud.bat     → Cloud API, порт 8080
  start-backend.bat   → Backend, порт 8000  (нужен Cloud)
  start-frontend.bat  → Интерфейс, порт 5173 (нужны Cloud + Backend)

ОСТАНОВКА
  stop-all.bat

ОШИБКА 10048 / PID 20144 / multiprocessing.spawn
  Зависший uvicorn (родитель 20144, дочерний spawn_main).
  1) stop-all.bat  (убивает дерево процессов)
  2) diagnose.bat  (порты + health)
  3) start-all.bat
  Не используйте uvicorn --reload на Windows.
  Папка backend\ (не nexus-backend\).

ОШИБКА 503 / тарифы не грузятся
  Cloud не запущен или порт 8080 занят (ошибка 10048).
  1) stop-all.bat
  2) start-all.bat
  3) В окне "Nexus Cloud 8080" должна быть строка без ERROR:
     Uvicorn running on http://127.0.0.1:8080
  Проверка в браузере: http://127.0.0.1:8080/health

ПОРТЫ
  8080 — nexus-cloud-server (авторизация, биллинг, ИИ)
  8000 — backend (прокси и IDE)
  5173 — frontend (Vite)

VERCEL
  Сайт на Vercel не видит ваш ПК. Нужен публичный backend + VITE_API_BASE.
  Подробнее: docs\DEPLOY_VERCEL.md

RouterAI
  Скопируйте nexus-cloud-server\.env.example → .env
  Укажите ROUTER_AI_MASTER_KEY

Примечание: bat-файлы только на латинице (ограничение cmd.exe).
Эта инструкция — на русском.
